**Основной адрес:** https://mc-hydraclient.github.io/

Сайт сделан на основе присланного шаблона `Vortex SIte.zip` и полностью переделан под бренд **HydraClient**. Это статический сайт: `index.html`, `style.css`, `script.js`, `config.js`.

- меню: `главная / функции / Видеообзор / Купить / Поддержка`;
- hero: `Minecraft Client 2026`, `HydraClient`, `Превосходство. Скорость. Победа.`;

- регистрация, вход и профиль аккаунта.

## Регистрация и профиль

В шапке есть кнопки **Войти** и **Регистрация**. Регистрация и вход работают **прямо на сайте** — GitHub, Supabase или другие внешние аккаунты не нужны.

При создании аккаунта пользователь сам вводит:

1. **Логин** — латинские буквы, цифры, `.`, `_`, `-`, от 3 до 32 символов;
2. **Имя пользователя** — от 2 до 32 символов;
3. **Пароль** — пользователь придумывает сам, минимум 8 символов;
4. **Повтор пароля** — для проверки.

После входа кнопка с именем в шапке открывает **личный кабинет**:

- **UID**, группа, дата регистрации, последний вход, E-mail, HWID;
- **Купленные товары** — `HydraClient 1.21.11`;
- **Подписка** — остаток дней;
- **Телеграм** — `Не привязан`;
- поле **Активация ключа** (ключи задаются в `config.js → activationKeys`, например `HYDRA7`, `HYDRA30`);
- кнопки **Активировать промокод**, **Купленные товары**, **Скачать Лаунчер**, **Сменить пароль**;
- ниже — форма смены пароля и кнопка **Выйти**.

Новый пароль сохраняется только после проверки старого пароля.

**Как хранится пароль:** пароль не сохраняется в открытом виде — хранится только PBKDF2-SHA256 хеш + соль.

**Где сохраняются аккаунты:** аккаунты сохраняются в общем облачном JSON-хранилище, указанном в `config.js → auth.usersApi`, а также кэшируются в `localStorage` браузера (`hydraclient_users_v1`, `hydraclient_session_v1`). Благодаря этому можно зарегистрироваться и потом зайти в аккаунт повторно, в том числе с другого устройства/браузера.

> Важно: это простое облачное хранилище для статического сайта, не полноценный защищённый backend. Для коммерческой защиты аккаунтов лучше подключить полноценную базу данных с серверной авторизацией.

## Скачивание лаунчера

Кнопка **Скачать Лаунчер** скачивает файл `HydraClient-Launcher.exe`.

Это Windows-лаунчер HydraClient с авторизацией:
- при запуске просит **логин и пароль** от аккаунта, созданного на сайте;
- проверяет аккаунт через общее хранилище сайта (`config.js → auth.usersApi`);
- если подписка активна (или навсегда) — открывает меню лаунчера и позволяет установить/запустить клиент;
- если подписка закончилась — доступ блокируется и показывается сообщение о завершении подписки.

Требования: Windows, Minecraft 1.21.11, Fabric Loader 0.16+, Fabric API, Java 21+.

## Что нужно заменить перед реальными продажами

В `config.js`:

- `auth.emailDomain` — домен для отображения E-mail в личном кабинете;
- `auth.usersApi` — URL общего JSON-хранилища аккаунтов (npoint/bin);
- `contact.discord` и `contact.telegram` — сейчас заглушки `XXXXXXX`;
- `payment.useRedirect` / `payment.redirectUrls` — ссылки на оплату;
- `payment.usePopup` / `payment.popupContact` — если продаёшь через сообщения;
- `video.url` — ссылка на YouTube-обзор;
- `screenshots` — реальные скриншоты вместо `placehold.co`.

## Публикация

Чтобы обновить сайт, загрузи в корень репозитория `mc-hydraclient/mc-hydraclient.github.io` файлы:

```text
index.html
style.css
script.js
config.js
HydraClient-Launcher.exe
HydraClient-1.21.11.jar
README.md
```

После коммита GitHub Pages сам обновит https://mc-hydraclient.github.io/.
